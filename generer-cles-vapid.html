🔑 Clés d'envoi des notifications

Cette page génère les deux clés dans ton navigateur. Rien n'est envoyé ni enregistré : ferme la page quand tu as copié les clés. Supprime ensuite ce fichier du dépôt.

1. Clé publique (non secrète)

À coller dans js/notifications.js, à la ligne const VAPID_PUBLIC = "";, entre les guillemets.

2. Clé privée (secrète)

Ne la colle jamais dans le chat, dans GitHub ni dans un fichier du dépôt.
Copie-la tout de suite dans ton gestionnaire de mots de passe. Elle sera ajoutée plus tard comme secret dans Cloudflare. Si tu la perds, il suffit de regénérer une paire, puis de réactiver les notifications sur chaque appareil.
