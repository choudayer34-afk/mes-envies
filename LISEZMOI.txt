Aucun ancien fichier de l'application n'est modifié. Aucune donnée nouvelle.

Score « Prêt à X % » : moyenne de cinq critères (réservations, logement, programme, documents, listes) ;
un critère sans objet (pas de liste, pas de billet, pas de dates) n'entre pas dans le calcul.
  Réservations : aucun billet = 0 ; billets mais aucun billet daté du retour = 50 % ; sinon 100 %.
  Programme : jours avec au moins un billet ou une étape / nombre de jours.
  Documents : billets avec fichier joint / billets ; papiers d'identité expirés avant le départ = plafonné à 50 %.
  Listes : articles cochés / articles.
« Il reste à faire » : chaque ligne a un bouton (Ajouter un billet, Ouvrir le programme, Ouvrir les listes...).
Tuiles d'Aujourd'hui : Valises x / y, Documents, Programme x jours sur y, À trier (nombre d'idées).
Prêt à partir : taille des pièces. Carte hors-ligne et rappel la veille : impossibles dans une application web.
